# Contributing

Issues and focused pull requests are welcome. Before proposing a change:

1. Keep extraction offline and dependency-free.
2. Add or update a synthetic fixture for changed behavior.
3. Run `python -m unittest discover -s tests -v`.
4. Explain user-visible behavior and limitations in the pull request.

Never submit scraped personal data, credentials, copyrighted page dumps, or
fixtures copied from a live client site.
